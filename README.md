# SweatQL website

This repository holds the published files of the SweatQL website, which is served at <https://sweatql.com/>.

The files are generated, so this repository doesn't take pull requests. Anything changed here is overwritten the next time the site is published.

## Report a bug or request a feature

To report a bug or ask for a feature, [open an issue](https://github.com/sweatql/sweatql-docs/issues/new) and pick the **Bug report** or **Feature request** form. Say what you did, what you expected, and what you saw instead.

Issues are public, so don't paste health data or screenshots with personal details.
